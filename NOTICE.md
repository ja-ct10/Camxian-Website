# Original design and assets

This project recreates the existing Camxian Technologies website at https://camxian.com/ at the owner's request. Original company content, branding, photographs, logos, masks, responsive images, and published layout styles were obtained from that site's publicly accessible pages and asset URLs on November 13, 2026.

- Company content, Camxian branding, and partner/customer marks retain their respective owners' rights.
- The source layout classes and published CSS are retained for reference fidelity. Elementor/WordPress application code and scripts are not required at runtime.
- `public/fonts/manrope.woff2` comes from the original site's Twenty Twenty-Five theme asset. Manrope is distributed under the SIL Open Font License: https://github.com/sharanda/manrope.
- The local Font Awesome 5 Free/Brands font assets come from the original site's Elementor font directory. Font Awesome Free fonts use SIL OFL 1.1; see https://fontawesome.com/license/free.
- Proxima Nova is served through the same Adobe kit referenced by the original site: https://use.typekit.net/gtm6uee.css. Adobe's font delivery and licensing terms continue to apply.

No new ownership or license for third-party assets is asserted by making this repository public.
